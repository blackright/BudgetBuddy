# Offline report fonts

Unmodified Noto Sans Regular and Bold, downloaded 2026-10-26 from the official Noto repository:

- https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
- https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Bold.ttf
- License: https://raw.githubusercontent.com/notofonts/noto-fonts/main/LICENSE

SIL Open Font License 1.1; full copyright and redistribution notice is bundled as OFL.txt. Fonts are loaded locally for report generation; no runtime font/network service is used. Latin, Greek and Cyrillic text and supported currency symbols use the bundled TrueType glyphs. Other scripts need appropriate fonts; unsupported characters must be surfaced rather than claimed as supported.
